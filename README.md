# Archipelago-Northgard

An [Archipelago](https://archipelago.gg) randomizer for **Northgard**, played in **Conquest
mode** or the roguelite **Bifrost mode**.
Complete your Conquest map by winning Chapter 7, or conquer Vanaheim across as many Bifrost
runs as it takes, solo or in co-op.

* See [how randomization works](worlds/northgard/docs/en_Northgard.md) (both modes: goal,
what gets shuffled)
* Follow the [setup guide](worlds/northgard/docs/setup_en.md) (full
install/connect walkthrough, including uninstall) for details.
